# DataPilot V4.0.1 验收与报告质量记录

3842；两步各返回4行，第二步2个NULL，均未截断；上传数据8行4列，income、hours
为int64。本次将其记录为**用户提供的既有验收结果**，没有读取当前 Streamlit
上传会话或调用 API 复核 Token，也不据此估算费用。

V4.0.1 本轮仅做本地模拟数据计算、审批审查、报告格式化及离线 pytest。没有读取

HTTP客户端；没有操作其他项目、Git 提交、标签、推送或远程发布。

使用 examples/demo_income.csv，所有 SQL 经过原字段及 AST 校验、独立进程；
Agent 测试逐步模拟人工审批，第一步完成后不自动生成或执行第二步。

| location | 步骤1 total_income | 步骤1 total_hours | 步骤2 weighted_avg_hourly |
| --- | ---: | ---: | ---: |
| A | 400 | 12 | 33.333333333333336 |
| B | 400 | 10 | 40 |
| C | 90 | 0 | NULL |
| D | 0 | 0 | NULL |

第二步沿用聚合 LEFT JOIN 和非零分母聚合，不使用 CASE、NULLIF 或新增语法。

## 审批审查与最小修复

现有页面没有 SQL 或计划的直接编辑入口，快照也为深拷贝；逐步审批、数据集变更
失效、取消、状态检查及无自动执行的正常路径已受约束。但服务层存在完整性缺口：
若应用内部在生成预览后替换候选 SQL，旧执行流程只比较传入与保存的 proposal_id，
未重新核算当前 SQL。Mock 证明其可到达执行器接口，未实际执行替换的 SQL。
这不是已经证明模型能修改任务内部状态或绕过 Python 进程边界的外部漏洞。

修复后：

- 完整计划审批时保存目标、数据集标识及全部步骤的摘要。
- SQL 生成及执行前再次核对已批准计划；计划变化即停止任务。
- SQL 审批标识绑定任务、步骤、计划摘要、实际 SQL；执行前重新计算并比较。
- 内部 SQL/计划发生变化时记录 APPROVAL_INVALIDATED，未提交执行器，要求新任务
  重新审核。不借此自动重新批准，也不自动重新生成 SQL。
- 上一步审批标识不能批准下一步；缺少人工确认、数据集变化、取消或状态不符仍
  阻止执行。错误审批标识不会执行 SQL，不能将静态对话审批作为页面执行授权。

可信应用仍负责授权。Python 私有属性不是针对恶意同进程代码的安全隔离；能任意
改写整个任务对象的代码也能改写摘要。本修复防止应用状态不一致，不宣称绝对隔离。

## 报告可读性

新增确定性本地摘要，直接按 SQL 原结果行显示：

```text
步骤1，结果第1行：地点（location）="A"；总收入（total_income）=400；总工时（total_hours）=12。
步骤2，结果第1行：地点（location）="A"；加权时薪（weighted_avg_hourly）=33.33（显示约数，完整精度见结果表）。
步骤2，结果第3行：地点（location）="C"；加权时薪（weighted_avg_hourly）=NULL（null）。
```

不跨步骤猜测拼接或补算字段；每行保留来源步骤、原结果行和原始字段名。明确单位
在原字段名或文本值中保持原样；未声明的币种、小时等单位不推定。整数保留精度，
小数用于阅读时可能显示约数，不改写 DataFrame。NULL、0、空字符串分开显示。

默认本地摘要每步最多10行、20列，长文本200字符，任何摘要省略、查询截断、异常
值或重名字段均提示。空结果不补造事实；无法安全解释的重复字段或异常结果结构
不产生假事实。原有完整结果表、实际返回行数、NULL统计和审计仍保留。

可选云端报告的数据事实也根据已授权的有限预览包本地排版，不再机械显示
“发送结果第1行，字段「值」的值为 A”。模型推断与建议继续沿用原受限校验，并
与数据事实分开展示。发送仍受独立授权及20行/20列/8KB限制，没有增加外发数据。
部分预览可能缩短字段或将非有限数规范化为空值，报告明确指向本地表核对。

旧任务缓存报告可直接根据原 preview_json 本地重新排版，不改写原报告、原审计或
Token记录，不再次请求模型。畸形出处包不生成数据事实。全新本地摘要不消耗任何
模型请求；正常两步仅规划及两次生成，选择原可选模型报告时才额外调用一次。

## 测试与使用

```powershell
.\.venv\Scripts\python.exe scripts/run_offline_tests.py -q
```

测试入口阻断真实配置默认加载与 requests HTTP，并强制跳过真实 API 测试。
新增测试覆盖精确两步结果、逐步审批、候选 SQL 替换、计划修改、数据集变更、
可读摘要、字段单位、大整数、NULL与0、截断、空结果、重复字段、异常单元格、
非法出处包及旧缓存排版，页面验收确认格式化不会多调用模型。

最终完整 pytest：**209项，207通过、0失败、2跳过**，耗时80.21秒；另有186个
通过的 subtest。新增16项测试：15项报告及审批测试、1项 Streamlit 端到端报告
测试。原有 V4.0、V3.1 与 SQL 安全测试保持通过；跳过项仅为真实 API 测试。

升级后请停止旧 Streamlit 进程并从本项目虚拟环境重新启动，后续分析新建任务，
避免沿用旧版本的审批对象。无需为查看旧结果的本地摘要再次调用 DeepSeek。
现有 V4.0 正常分析路径保持兼容；变化是审批完整性检查更严格和报告展示改善。
界面与 README 标识 V4.0.1，不等同已发布远程版本或重新完成云端验收。
